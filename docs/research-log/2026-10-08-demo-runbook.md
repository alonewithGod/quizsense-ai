# 연구 기록 - 발표용 실행 절차 완성

- 일자: 2026-10-08

## 목적

발표용 Windows PC에서 설치 확인, 실제 시연, 결과 저장과 장애 복구를 같은 순서로 수행하고,
검증되지 않은 예상값 대신 실제 실행 자료만 제출 증빙으로 남길 수 있게 한다.

## 변경 내용

- Windows 11과 Python 3.12 기준 최초 설치 및 발표 당일 사전 점검 명령을 문서화했다.
- 평서문과 강의형 질문 두 개를 사용하는 3분 시연 순서를 작성했다.
- 사전 점검 JSON, 세션 JSON·CSV와 실제 화면 스크린샷 세 장의 보존 기준을 정했다.
- 마이크, 패키지, Ollama, 모델, 질문 탐지, 답변 생성, 저장 실패에 대한 복구표를 추가했다.
- 실제 세션 JSON에서 연구일지로 옮길 지표와 기록하면 안 되는 예상값을 구분했다.

## 실행 조건

- 문서의 명령과 저장 경로를 현재 코드 및 README와 대조했다.
- 자동 테스트와 정적 검사는 저장소의 Python 3.12 가상환경에서 실행한다.
- 실제 Windows UI, 마이크, faster-whisper 모델 실행과 Ollama 응답 생성은 사용하지 않았다.

## 결과

- `python -m pytest`: 29개 통과, 실패 0개
- `python -m ruff check quizsense tests`: 통과
- `python -m py_compile quizzesense_ai.py quizsense/*.py`: 통과
- 기본 회귀 평가 40문장: 정확도 1.0000, 정밀도 1.0000, 재현율 1.0000, F1 1.0000
- 강의형 전사 시나리오 30문장: TP 12, TN 18, FP 0, FN 0, 정확도와 F1 1.0000
- README와 발표 절차의 사전 점검 명령, 앱 실행 명령, 증빙 저장 경로가 현재 구현과 일치함을 확인했다.

## 문제점

- 실제 장비 화면을 사용할 수 없어 스크린샷 자체는 생성하지 않았고 촬영 지점만 명시했다.
- PowerShell 명령은 문서 검토 대상이며 Windows 발표용 PC에서의 실제 실행 확인이 남아 있다.

## 다음 작업

발표용 PC에서 문서 순서대로 사전 점검과 강의형 질문 시연을 수행하고, 실제 사전 점검 JSON,
세션 JSON·CSV 및 스크린샷 세 장을 제공하여 종단 지연시간과 결과를 연구일지에 기록한다.
