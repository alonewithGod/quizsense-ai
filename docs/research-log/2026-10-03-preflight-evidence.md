# 연구 기록 - 사전 점검 증빙 저장

- 일자: 2026-10-03

## 목적

발표용 PC의 마이크·faster-whisper·Ollama 준비 상태와 실행 설정을 시점이 포함된 파일로 남겨,
이후 종단 실험의 실행 조건을 재현하고 제출 자료의 근거로 사용할 수 있게 한다.

## 변경 내용

- 사전 점검 CLI에 `--output` 옵션을 추가했다.
- 결과 파일에 UTC 실행시각, 전체 준비 여부, Whisper·Ollama 핵심 설정과 항목별 결과를 저장한다.
- 설정 검증이 실패한 경우에도 실패 원인을 포함한 JSON 증빙 파일을 생성한다.
- 기존 `--json` 표준 출력 형식은 변경하지 않았다.
- README에 발표용 PC 실행 예시를 추가하고 실제 장비 결과 파일은 Git에서 제외했다.

## 실행 조건

- Python 3.12
- 자동 테스트에서는 모의 마이크 이름과 임의 모델명을 사용했다.
- 실제 마이크, 음성 파일, faster-whisper 모델 실행, Ollama 응답 생성은 사용하지 않았다.

## 결과

- `python -m pytest`: 27개 통과, 실패 0개
- `python -m ruff check quizsense tests`: 통과
- `python -m py_compile quizzesense_ai.py quizsense/*.py`: 통과
- 기본 회귀 평가 40문장: 정확도 1.0000, 정밀도 1.0000, 재현율 1.0000, F1 1.0000
- 강의형 전사 시나리오 30문장: TP 12, TN 18, FP 0, FN 0, 정확도와 F1 1.0000
- 잘못된 언어 설정으로 실행한 사전 점검은 종료 코드 1을 반환하고 UTC 실행시각, 입력 설정,
  실패 원인이 포함된 JSON 파일을 생성했다.

## 문제점

- 저장 기능과 파일 구조를 검증한 것으로 실제 발표용 PC의 준비 완료를 의미하지 않는다.
- 종단 지연시간과 음성 인식 정확도는 사전 점검 파일이 아닌 실제 세션 JSON으로 별도 측정해야 한다.
