# 연구 기록 - 실행 설정 검증 강화

- 일자: 2026-10-01

## 목적

발표용 PC에서 잘못된 환경변수 때문에 실행 중 예기치 않은 오류가 발생하지 않도록 숫자 설정을
실행 전에 검증하고, 수정할 설정의 이름과 입력값을 명확하게 안내한다.

## 변경 내용

- 정수·실수 환경변수 변환 실패 메시지에 환경변수명과 실제 입력값을 포함했다.
- `NaN`, 양의 무한대, 음의 무한대를 실수 설정으로 사용할 수 없도록 차단했다.
- 직접 생성한 설정 객체에서도 비정상적인 실수 값이 검증을 통과하지 않도록 보완했다.
- 잘못된 정수와 비유한 실수 입력에 대한 자동 테스트를 추가하고 README에 동작을 설명했다.

## 실행 조건

- Python 3.12
- 실제 마이크, 음성 파일, faster-whisper 모델 실행, Ollama 응답 생성은 사용하지 않았다.

## 결과

- `python -m pytest`: 25개 통과, 실패 0개
- `python -m ruff check quizsense tests`: 통과
- `python -m py_compile quizzesense_ai.py quizsense/*.py`: 통과
- 기본 회귀 평가 40문장: 정확도 1.0000, 정밀도 1.0000, 재현율 1.0000, F1 1.0000
- 강의형 전사 시나리오 30문장: TP 12, TN 18, FP 0, FN 0, 정확도와 F1 1.0000
- 잘못된 정수 1종과 비유한 실수 3종(`NaN`, `inf`, `-inf`)의 자동 차단을 확인했다.

## 문제점

- 설정 형식 오류를 실행 전에 차단하는 개선이며 실제 마이크·STT·Ollama 종단 동작은 검증하지 않았다.
- Ollama 주소의 실제 연결 가능성과 모델 설치 여부는 기존 사전 점검 명령으로 별도 확인해야 한다.
