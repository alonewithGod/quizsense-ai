# 연구 기록 - 세션 측정값 검증

- 일자: 2026-10-06

## 목적

응답 지연시간과 질문 탐지 점수의 비정상 값이 JSON·CSV 및 요약 통계에 포함되는 것을 막아
제출용 실험 결과의 무결성을 높인다.

## 변경 내용

- STT 및 Ollama 응답 지연시간이 유한한 0 이상의 값인지 기록 전에 검증한다.
- 질문 탐지 점수가 유한한 0~1 범위인지 기록 전에 검증한다.
- 음수 지연시간을 0으로 조용히 보정하던 동작을 제거하고 원인을 확인할 수 있는 오류로 바꿨다.
- 검증에 실패한 항목이 세션 이력과 요약 통계에 추가되지 않는지 자동 테스트를 추가했다.

## 실행 조건

- Python 3.12
- 자동 테스트에 `NaN`, 무한대, 음수와 범위를 벗어난 탐지 점수를 입력했다.
- 실제 마이크, faster-whisper 모델 실행, Ollama 응답 생성은 사용하지 않았다.

## 결과

- `python -m pytest`: 29개 통과, 실패 0개
- `python -m ruff check quizsense tests`: 통과
- `python -m py_compile quizzesense_ai.py quizsense/*.py`: 통과
- 기본 회귀 평가 40문장: 정확도 1.0000, 정밀도 1.0000, 재현율 1.0000, F1 1.0000
- 강의형 전사 시나리오 30문장: TP 12, TN 18, FP 0, FN 0, 정확도와 F1 1.0000
- `NaN`, 무한대, 음수 지연시간과 범위 밖 탐지 점수를 모두 거부했고 실패 후 기록 건수는 0이었다.

## 문제점

- 저장 계층의 데이터 검증이며 실제 장치의 지연시간이나 음성 인식 정확도를 측정한 결과는 아니다.
- 실제 실행에서 비정상 값이 발생하면 해당 원인을 별도 진단해야 한다.
