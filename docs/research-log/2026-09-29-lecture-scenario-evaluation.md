# 연구 기록 - 강의형 전사 시나리오 평가

- 일자: 2026-09-29

## 목적

기존의 독립 문장 회귀 평가를 보완하기 위해 강의 흐름을 반영한 전사문을 주제별로 구성하고,
질문 탐지 결과를 전체 및 시나리오별로 재현 가능하게 측정한다.

## 변경 내용

- 데이터베이스·네트워크·운영체제 강의 흐름 3개와 문장 30개를 평가 데이터로 추가했다.
- 평가기는 `scenario`와 `language` 열이 있으면 각 값의 표본 수, 혼동행렬, 정확도, 정밀도,
  재현율, F1을 JSON에 함께 저장한다.
- 오분류 문장은 기존과 동일하게 `errors`에 원본 열, 예측, 점수, 판단 근거와 함께 저장한다.
- 시나리오별 집계가 동작하는지 자동 테스트를 추가하고 README에 실행 명령과 평가 범위를 적었다.

## 실행 조건

- Python 3.12.14
- 입력: 자체 작성한 한국어 강의형 전사문 30개(질문 12개, 비질문 18개)
- 실제 마이크, 음성 파일, faster-whisper 전사, Ollama 응답 생성은 사용하지 않았다.

## 결과

- `python -m pytest`: 20개 통과, 실패 0개
- `python -m ruff check quizsense tests`: 통과
- `python -m py_compile quizzesense_ai.py quizsense/*.py`: 통과
- 기본 회귀 평가 40문장: 정확도 1.0000, 정밀도 1.0000, 재현율 1.0000, F1 1.0000
- 강의형 전사 시나리오 30문장: TP 12, TN 18, FP 0, FN 0
- 강의형 전사 시나리오 전체: 정확도 1.0000, 정밀도 1.0000, 재현율 1.0000, F1 1.0000
- 데이터베이스·네트워크·운영체제 각 10문장: 정확도와 F1이 각각 1.0000

## 문제점

- 평가 데이터는 실제 강의를 녹음·전사한 외부 자료가 아니라 자체 작성한 텍스트이므로 실제 강의
  일반화 성능을 나타내지 않는다.
- 교실 소음, 화자 거리, 발음, 음성 구간 분리, faster-whisper 전사 오류의 영향은 측정하지 않았다.
- 세 시나리오 모두 현재 규칙이 명확히 처리하는 질문 표현을 포함하므로 더 다양한 간접 질문과
  불완전한 전사문을 추가해야 한다.

결과, Ollama 응답, 세션 지연시간 JSON을 함께 저장해 텍스트 평가와 실제 종단 결과를 비교한다.
